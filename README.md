# algonquin-cst-portfolio
Welcome to my portfolio of lab work, scripts, and more. 
I've just finished my second term as a Computer Systems Technician - Networking student at Algonquin College in Ottawa.

Level One of my program consisted of the following courses:
    - GNU/Linux Desktop Support (using RHEL 9.6 in VMWare Workstation Pro 17.5)
    - Windows Desktop Support (automating tasks using PowerShell)
    - Networking Fundamentals (CCNA: Introduction to Networks on Netacad)
    - Numeracy and Logic (special focus on CNS, logic gates, and statistics/probability)
    - Achieving Success in Changing Environments (collaborating with peers & navigating this ever-changing world)

Inside the level-one folder are the scripts I worked on in my first semester. I'm excited to continue automating tasks at the Active Directory-enabled domains and Enterprise networks in levels two and three. More information about my current program can be found here: https://camlam.ca/cst-program.html
