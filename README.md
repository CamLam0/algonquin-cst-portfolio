# algonquin-cst-portfolio
Welcome to my portfolio of lab work, scripts, and more. 

This repository stores my finalized scripts and projects from my first year in Algonquin College's Computer Systems Technician - Networking program.
The L1, L2, and L3 folders contain my work from each semester of my first year of study, separated by course. 
I'm grateful for all the assistance I've had from professors and friends working on these assignments, scripts, and projects. 
Reflecting on this work has shown me how much I've learned and further inspired me to keep pushing the limits of what I know.

More information about my program can be found on my website: https://camlam.ca/cst-program.html
